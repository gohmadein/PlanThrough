# PlanThrough

可递归穿透的项目时空地图：一张图融合甘特时间轴、思维导图层级、进度归并和风险传递。

## 本地运行

需要 Node.js 22.13 或更高版本。

```powershell
npm install
npm run dev
```

按照终端显示的本地地址在浏览器中打开。

## 使用方式

1. 首次打开时设置项目名称、起止时间、一级节点数量和纵轴分类。
2. 点击节点后在右侧修改时间、分类、进度、权重和风险。
3. 点击节点左侧的 `+` 展开子节点；可同时展开多个节点。
4. 在右侧添加多个前置节点，并选择“完成后开始”或“可并行”。
5. 使用顶部缩放按钮切换全局或精细时间颗粒度。
6. 点击“导出”生成 JSON 文件；其他人在网站中点击“导入”即可继续使用。

编辑节点后，点击编辑面板右上角的 `×` 即可收回面板。时间轴会根据项目跨度和缩放比例自动在年、季度、月、周、日之间切换。

顶部“项目查看”会进入独立的项目库页面，可以搜索、删除项目，也可以在新页面打开任意旧项目。节点上的回形针按钮用于上传和管理文件；点击文件名可下载，点击“删除”可移除。附件内容目前只保存在当前浏览器，不随 JSON 项目文件传输。

详细规则见 [PRODUCT_SPEC.md](./PRODUCT_SPEC.md)。
